## ✨ Features

- Live window previews with one-click focus
- Drag-to-move windows from the panel
- Window tiling & snap (left, right, fullscreen, center)
- Pin favorite windows to the top
- Quick Switcher (`⌥ + Tab`) — spotlight-style window search
- Session management — save and restore window layouts
- Desktop file organizer — auto-group files by type
- Multi-language support: English 🇬🇧, Turkish 🇹🇷, Spanish 🇪🇸

Or open `DesktopOrganizer.xcodeproj` in Xcode and press `⌘ + R`.
